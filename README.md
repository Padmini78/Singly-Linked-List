## Singly Linked List

A simple web-based implementation of Singly Linked List using HTML, CSS and JavaScript.

## Features

- Insert a node
- Delete a node
- Search a node
- Display the linked list
- Shows the current state after every operation

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Enter a value in the input field.
2. Use the Insert button to add a node.
3. Use the Delete button to remove a node.
4. Use the Search button to find a node.
5. Use the Display button to view the current linked list.
